# Debate Hub

Debate Hub is a real-time debate app where people create topics, join 1v1 or group debates, and post Pro, Con or Neutral arguments that appear instantly on every connected device. A "Live now" section shows debates that are active right now and how many people are watching, so anyone can jump in. Arguments can be upvoted, a stance bar shows how the community is leaning, and you get notifications when the other side posts in a debate you joined. Nothing is stored in a database.

Follow us on Facebook: https://www.facebook.com/Factsbyexperiences

## Features
- Create debates by category (Politics, Technology, Science, Philosophy, Sports)
- 1v1 and group formats
- Live arguments, joins and upvotes across devices
- Live now: active debates with viewer counts
- Notifications for messages and joins in your debates
- Pro vs Con community stance gauge
